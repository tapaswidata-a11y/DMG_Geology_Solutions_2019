## 📚 Pedagogical Architecture

Every question module follows an uncompromising 3-tier academic structure:

1. **Part I: Theoretical Foundation & Chapter Masterclass**
   - In-depth theoretical exposition of the underlying geological and thermodynamic principles **before** presenting the question.
   - Verbatim excerpts and citations from standard university reference textbooks.
   - High-resolution scanned diagrams, AFM ternary plots, isochrons, stereonets, and photomicrographs.
   - Complete mathematical proofs and stoichiometric balance equations.

2. **Part II: Official Exam Question Statement & Critical Option Dissection**
   - Exact question statement and options from the official DGMS 2019 paper.
   - Verified answer banner with textbook page references.
   - Exhaustive rationale validating the correct option.
   - Detailed refutations explaining why each distractor is incorrect.

3. **Part III: Synthesis Reference Tables & High-Yield Practice Questions**
   - Summary comparative classification matrices.
   - 8+ curated exam-standard conceptual and numerical practice questions with worked solutions.

## 🛠️ Build and Compilation Instructions

### Generating Print-Ready PDFs
Each module is compiled from HTML to publication-grade PDF using [WeasyPrint](https://weasyprint.org/):
```bash
python3 -c "import weasyprint; weasyprint.HTML('Q15_Oblique_Slip_Faults_Complete_Guide.html', base_url='.').write_pdf('Q15_Oblique_Slip_Faults_Complete_Guide.pdf')"
```

### Rebuilding the Master Portal
To regenerate the unified portal `index.html`:
```bash
python3 build_master_site.py
```
