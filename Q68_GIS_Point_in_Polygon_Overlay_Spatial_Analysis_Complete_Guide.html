Question 68: Vector GIS Spatial Analysis & Point-in-Polygon Overlay Operations

Geospatial Overlay Geometry, Topological Relationships, and Spatial Join Attribute Binding
Official Examination Question
In a GIS database, the location of meteorological station with respect to a specific land use can be identified using
(a) Line to polygon overlay
(b) Polygon on polygon overlay
(c) Point in polygon overlay [CORRECT]
(d) Line on line overlay
Verified Answer Key

Correct Option: (c) Point in polygon overlay — In vector GIS spatial modeling, a meteorological station is represented geometrically as a zero-dimensional point feature ($x, y$ coordinate pair), while a land use zone (e.g., forest, agriculture, urban) is represented as a two-dimensional polygon feature (areal parcel). Determining which land-use parcel encompasses a meteorological station requires a Point-in-Polygon overlay (or spatial join).

1. Vector Data Model Geometry & Spatial Overlay Principles

In a Geographic Information System (GIS), vector data structures represent real-world spatial phenomena using three fundamental topological primitives:

  • Points (0D): Discrete locations with no length or area, defined by a single coordinate pair $(x, y)$. Examples: Meteorological stations, groundwater boreholes, seismic observation stations, mineral deposit localities.
  • Lines / Polylines (1D): Linear features with length but no width, defined by ordered sequences of vertices. Examples: Fault lines, river channels, transport networks, geological strike lines.
  • Polygons (2D): Enclosed two-dimensional planar areas with perimeter and area, defined by closed boundary lines. Examples: Land use / land cover (LULC) classes, lithological units, watershed catchment basins, forest zones.

3. Point-in-Polygon Algorithms

Computational geometry engines in GIS software (e.g., QGIS, ArcGIS, PostGIS) evaluate point-in-polygon containment using rigorous mathematical algorithms:

  • Ray-Casting Algorithm: A semi-infinite horizontal ray is projected from the test point $(x_0, y_0)$ to infinity along the $+x$ axis. If the ray intersects the polygon boundary an odd number of times, the point lies inside the polygon. If it intersects an even number of times (or zero), the point lies outside.
  • Winding Number Algorithm: Counts the total number of times the polygon boundary winds around the point; a non-zero winding number indicates the point is interior.

4. Comprehensive Option Analysis

  • (a) Line to polygon overlay: Incorrect. Used for linear features (roads, streams, seismic profiles) intersecting polygons, not discrete point locations like meteorological stations.
  • (b) Polygon on polygon overlay: Incorrect. Used when both input layers are planar polygons (e.g., overlaying a soil map on a geology map).
  • (c) Point in polygon overlay: Correct. A meteorological station is fundamentally a point feature, and land use is a polygon feature. Point-in-polygon overlay directly identifies the specific land use parcel containing each meteorological station.
  • (d) Line on line overlay: Incorrect. Used only to find intersections or overlaps between two linear networks.
