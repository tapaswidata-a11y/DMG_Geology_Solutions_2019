1. Theoretical Foundation: Point-in-Polygon Spatial Overlay

In vector GIS and computational geometry, spatial overlay superimposes two or more geographic layers sharing a common coordinate reference system to evaluate topological relationships between intersecting geometries. When an overlay combines a point layer with a polygon layer, the operation is formally termed a Point-in-Polygon Overlay (Chang; Burrough & McDonnell; O'Rourke):

By international GIS definition, a point-in-polygon overlay is an overlay method used to determine as to which points lie within the boundary of a polygon (Option D):

$$\text{Overlay}(P, Q) = \{ p_i \in P \mid p_i \text{ is topologically contained inside polygon } q_j \in Q \}$$

POINT-IN-POLYGON OVERLAY (Option D) Point Layer (e.g. Water Wells, Boreholes) Polygon Layer (e.g. Geological Formations, Districts) Points: Retains point geometry but appends all polygon attribute fields to each point record (Spatial Join: which well lies in which rock unit).
Line-in-Polygon Overlay Line Layer (e.g. Rivers, Faults) Polygon Layer (e.g. Mining Concessions) Lines: Splits lines at polygon boundaries; attributes of polygons transferred to intersecting line segments.
Polygon-on-Polygon Overlay Polygon Layer 1 (e.g. Soil Map) Polygon Layer 2 (e.g. Land Use) Polygons: Creates new intersecting polygon slivers possessing combined attributes from both parent layers (Intersect/Union).

Computational Geometry: The Ray-Casting (Even-Odd) Algorithm

How does a computer mathematically decide whether a point $(x_0, y_0)$ lies inside an irregular polygon? The standard algorithm used in GIS software is the Ray-Casting Algorithm (Jordan Curve Theorem):

  • A semi-infinite horizontal test ray is cast from test point $(x_0, y_0)$ extending to $+\infty$ along the $+X$ axis.
  • The algorithm counts the total number of intersections ($N$) between the ray and the polygon's bounding line segments.
  • Containment Rule:
    • If $N$ is ODD ($N = 1, 3, 5, \dots$), the point lies INSIDE the polygon.
    • If $N$ is EVEN ($N = 0, 2, 4, \dots$), the point lies OUTSIDE the polygon.

In practical geological GIS, point-in-polygon overlay enables queries such as: Which mineral exploration drill-holes fall inside the newly leased quarry polygon? or Which earthquake epicenters fall inside active seismotectonic graben zones?

2. Official Examination Question & Forensic Option Analysis
QUESTION 146
What is ‘point-in-polygon’ overlay ?
A A method interpolating point data
B An overlay method used to determine the distance between a point and its nearest neighbouring polygon
C An overlay method used to reclassify polygon data
D An overlay method used to determine as to which points lie within the boundary of a polygon
CORRECT ANSWER: OPTION D (An overlay method used to determine as to which points lie within the boundary of a polygon)
OPTION D • CORRECT
An overlay method used to determine as to which points lie within the boundary of a polygon

By universal vector GIS definition (Chang, Ch. 11; Burrough & McDonnell; Bangar, p. 219), a point-in-polygon overlay evaluates the topological containment relationship between a point layer and a polygon layer to determine exactly which point features fall within the spatial perimeter boundary of each polygon, transferring the polygon attributes into the point records.

OPTION A • DISTRACTOR
A method interpolating point data

Interpolation (IDW, Kriging) creates continuous raster surfaces from discrete points. It has nothing to do with polygon topological overlays.

OPTION B • DISTRACTOR
An overlay method used to determine the distance between a point and its nearest neighbouring polygon

Determining distances to nearest features is a proximity analysis tool (e.g. Near tool, Generate Near Table, or Cost Distance), not an overlay operation.

OPTION C • DISTRACTOR
An overlay method used to reclassify polygon data

Reclassification changes attribute values of a single layer based on lookup rules. It does not perform geometric topological overlays between points and polygons.

1. In a point-in-polygon overlay between an exploration borehole point layer and a regional lithology polygon layer, what attributes will appear in the output attribute table?
Answer: The output attribute table contains all original borehole attributes (collar ID, depth, assay grade) PLUS all attributes from the intersecting lithology polygon (formation name, age, lithological rock group).
Point-in-polygon overlay performs a spatial join that enriches point data with host polygon attributes.
2. What is the Winding Number algorithm in computational geometry for point-in-polygon testing?
Answer: An algorithm that computes the total number of times the polygon boundary winds or wraps around the test point (winding number $W \ne 0 \implies \text{Inside}$).
The winding number handles self-intersecting complex polygons more robustly than the basic even-odd ray test.
3. What is a "Spatial Join" in GIS software?
Answer: Joining attribute tables of two layers based on their relative geographic location or topological relationship (e.g. containment, nearest, or intersection) rather than a shared common alphanumeric key field.
Point-in-polygon overlay is the classic implementation of a spatial join based on containment.
4. What is a "Sliver Polygon" in vector GIS overlay?
Answer: A tiny, spurious, elongated polygon artifact generated along boundaries when overlaying two layers that share the same real-world boundary digitized slightly differently.
Slivers are removed using topological snapping tolerances or cluster tolerance rules.
5. If a test ray cast from a point intersects a polygon's bounding edges exactly twice, is the point inside or outside the polygon?
Answer: Outside the polygon.
By the even-odd rule: 2 is an even number, meaning the ray enters and exits an exterior lobe without containing the origin point.
6. What happens if a point falls exactly on the boundary line segment of a polygon during a point-in-polygon query?
Answer: It depends on the software's boundary convention; standard OGC specifications treat the boundary as part of the polygon interior (ST_Covers) or evaluate it under specific vertex-touching edge rules.
Software typically defines inclusion if the point lies on the left/top boundary edges to prevent double-counting between adjacent polygons.
7. What is the Dimensionally Extended 9-Intersection Model (DE-9IM)?
Answer: A topological framework that formally defines the spatial relationship between two geometries ($A$ and $B$) by evaluating the intersection dimensions ($0, 1, 2$, or empty) of their Interior, Boundary, and Exterior.
DE-9IM forms the mathematical foundation of spatial SQL predicates (ST_Within, ST_Contains, ST_Crosses).
8. What is the first computational screening step a spatial DBMS executes before running the ray-casting point-in-polygon test?
Answer: The Minimum Bounding Box (MBR / BBOX) test.
If the point's coordinates $(x, y)$ fall outside the polygon's simple bounding box ($X_{\text{min}}, Y_{\text{min}}, X_{\text{max}}, Y_{\text{max}}$), the point is instantly rejected without evaluating hundreds of complex boundary vertices.
