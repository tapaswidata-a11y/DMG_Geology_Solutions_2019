1. Theoretical Foundation: Proximity Analysis and the Buffer Operation

In Geographic Information Systems (GIS), proximity analysis is one of the foundational geometric operations used to evaluate spatial relationships based on distance. Among proximity operators, the Buffer Operation is the most widely utilized vector geoprocessing tool (Chang; Burrough & McDonnell; Bangar):

By international GIS definition, a buffer operation generates a polygon area enclosing all locations situated within a specified, set distance (the buffer distance, $r$) from an input target feature (point, line, or polygon):

$$\text{Buffer}(S, r) = \{ p \in \mathbb{R}^2 \mid \min_{q \in S} \text{dist}(p, q) \le r \}$$

where $S$ is the input geometry feature, $r$ is the user-defined buffer distance, and $\text{dist}(p, q)$ is the Euclidean (or geodesic) distance between point $p$ and any point $q$ on feature $S$.

Input Feature Geometry Generated Buffer Polygon Geometry Mathematical Boundary Shape Geological & Environmental Application
Point Feature (e.g. Borehole, Blast Site) A solid circular polygon centered on the point with radius equal to buffer distance $r$. $$\text{Area} = \pi r^2$$ Blast hazard safety exclusion zone around a quarry; radius of influence around an abstraction well.
Line Feature (e.g. Fault, River, Road) A continuous corridor band polygon extending distance $r$ on both sides of the line, terminating in rounded or flat end caps. $$\text{Width} = 2r + \text{Length of line}$$ Riparian protection corridor along a river; seismic ground-rupture hazard setback zone along a fault scarp.
Polygon Feature (e.g. Mine Lease, National Park) An expanded external boundary zone (external buffer) or an interior setback zone (negative/internal buffer). Exterior or interior offset polygon Statutory $1\text{ km}$ eco-sensitive buffer zone around wildlife sanctuaries; setback zone inside mining lease.

Buffer Variations in Advanced Geoprocessing:

  • Fixed-Distance Buffering: All features in the layer receive the identical buffer radius (e.g. $100\text{ m}$ around all streams).
  • Variable-Distance (Attribute) Buffering: Buffer distance is read dynamically from an attribute column (e.g. streams buffered according to stream order: 1st order $= 20\text{ m}$, 4th order $= 100\text{ m}$).
  • Multi-Ring (Concentric) Buffering: Generates a series of concentric concentric distance bands (e.g. $100\text{ m}, 200\text{ m}, 500\text{ m}, 1000\text{ m}$) for distance-decay risk modeling.
  • Dissolved vs. Undissolved: Overlapping buffer circles can either be merged into a single continuous multipart polygon (Dissolved) or preserved as individual intersecting polygons (Undissolved).

2. Official Examination Question & Forensic Option Analysis
QUESTION 143
For which of the following applications, the buffer operation can be used in GIS ?
A Calculating the distance from one point to another
B Calculating the area of overlap between two polygon data layers
C Determining the area within a set distance from a point, line or area feature
D Calculating the number of observations within a set distance of a point line or area feature
CORRECT ANSWER: OPTION C (Determining the area within a set distance from a point, line or area feature)
OPTION C • CORRECT
Determining the area within a set distance from a point, line or area feature

By international GIS definition (Chang, Ch. 11; Burrough & McDonnell; Bangar, p. 219), the fundamental purpose of the buffer operation in GIS is to delineate and output a polygon defining the continuous geographic area lying within a specified (set) distance from an input point, line, or area (polygon) feature.

OPTION A • DISTRACTOR
Calculating the distance from one point to another

Calculating straight-line distance between two coordinates is performed using the Euclidean distance formula ($d = \sqrt{\Delta x^2 + \Delta y^2}$) or network distance tools, not the polygon buffer tool.

OPTION B • DISTRACTOR
Calculating the area of overlap between two polygon data layers

Computing polygon overlap area is the domain of topological overlay operations (specifically Intersect or Clip), not buffering.

OPTION D • DISTRACTOR
Calculating the number of observations within a set distance of a point line or area feature

Counting observations is a secondary spatial query or point-in-polygon aggregation operation. While a buffer polygon can subsequently be used to clip points, the buffer operation itself determines the spatial area within the set distance.

1. What geometry type is always produced as the output of a GIS buffer operation, regardless of whether the input is a point, a line, or a polygon?
Answer: A Polygon (areal) layer.
A buffer transforms 0D points and 1D lines into 2D areal zones.
2. What is a "Negative Buffer" and to which geometry type can it be applied?
Answer: A buffer created with a negative distance ($-r$) that shrinks the feature inward from its boundary; it can only be applied to Polygon features.
Negative buffering defines statutory setback boundaries inside mining leases or building lots.
3. What is the difference between a Euclidean Buffer and a Geodesic Buffer in GIS software?
Answer: A Euclidean buffer calculates distance on a 2D flat planar projected plane; a Geodesic buffer calculates true great-circle distance across the curved Earth ellipsoid.
Over continental or global extents, planar Euclidean buffers suffer massive distortion, requiring geodesic buffering.
4. In statutory Indian environmental mining regulations, what is the mandatory eco-sensitive buffer zone typically mandated around the boundary of a National Park or Wildlife Sanctuary?
Answer: A $10\text{ kilometer}$ default Eco-Sensitive Zone (ESZ) or site-specific $1\text{ km}$ buffer where commercial mining is strictly prohibited by Supreme Court mandates.
GIS polygon buffering is the primary tool used by State Pollution Control Boards and MoEFCC to verify mining compliance.
5. What happens when the "Dissolve" option is selected during a buffer operation on multiple closely spaced points?
Answer: Overlapping buffer circles are fused into a single seamless, continuous multipart polygon, eliminating internal intersecting boundaries.
If undissolved, overlapping buffer circles overlap as separate independent polygon entities.
6. How does a raster buffer differ from a vector buffer?
Answer: A raster buffer calculates Euclidean distance for every raster grid cell from target source cells (using Euclidean Distance / cost-distance) and reclassifies cells where $\text{dist} \le r$ to a value of $1$.
Vector buffering uses trigonometric coordinate offset algorithms; raster buffering uses grid cell distance transforms.
7. What is a "Variable-Distance Buffer"?
Answer: A buffer whose width varies for each individual feature based on numeric values stored in a specified attribute table column.
Example: Buffering roads by road hierarchy width (National Highway $= 60\text{ m}$, State Highway $= 30\text{ m}$, Village Road $= 10\text{ m}$).
8. What is the GIS workflow to identify all schools located within $500\text{ meters}$ of an active mining haul road?
Answer: (1) Run Buffer on the haul road line layer with distance $= 500\text{ m}$; (2) Perform Spatial Overlay (Point-in-Polygon / Select by Location) of the school point layer intersecting the haul road buffer polygon.
Buffering followed by spatial selection is the classic GIS proximity screening workflow.
