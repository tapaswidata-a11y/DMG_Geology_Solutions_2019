2. Detailed Geological Masterclass: Coordinate Systems and Dimensionality in GIS

The fundamental architecture of Geographic Information Systems is rooted in planar cartography and coordinate reference systems:

  • Standard Planar 2D Coordinates: Every primary GIS layer, projected coordinate system (e.g., UTM, Universal Transverse Mercator, Lambert Conformal Conic, State Plane), and geographic coordinate system (GCS, WGS84) defines any surface location using a two-dimensional coordinate pair: $$\text{Location} = (X, Y) \quad \text{or} \quad (\text{Easting, Northing}) \quad \text{or} \quad (\text{Longitude, Latitude})$$
  • 2.5D vs 3D Extensions: While modern elevation data (DEM, TIN) attaches an elevation attribute $Z$, classical GIS data structures (shapefiles, coverages) are topologically planar 2D systems where $Z$ is treated as a single-valued attribute rather than an independent spatial volumetric dimension (termed $2.5\text{D}$).
  • In standard introductory curricula and competitive examinations, location on a map or GIS layer is officially formulated in 2-dimensional coordinates $(X,Y)$.
