2. Detailed Geological Masterclass: Raster Data Compression vs Vector Models

Spatial databases employ distinct data structures to optimize computer memory and processing efficiency for raster and vector models:

Data Model Data Structure Name Architectural Mechanism
Vector Spaghetti Model A rudimentary, non-topological vector data structure where lines and polygons are recorded as independent, unstructured "spaghetti" strands of $(X, Y)$ coordinate pairs without storing adjacency, connectivity, or node topology. Shared borders between adjacent polygons are digitized and stored twice.
Raster Quadtree A hierarchical raster spatial index tree structure that recursively subdivides an image into quadrants (NW, NE, SW, SE) until all pixels in a sub-quadrant share identical attribute values.
Run-Length Encoding (RLE) A lossless raster compression method that stores rows of continuous identical cell values as a pair: (attribute value, run length / count).
Block Encoding A two-dimensional extension of RLE that compresses contiguous raster cells into square blocks of varying sizes.

Because the Spaghetti model is strictly a vector data structure, it is NOT a raster data structure.

3. Critical Option Elimination & Exam Traps

  • Option B (Spaghetti) is correct (not a raster structure): Classic rudimentary vector model lacking topological relationships.
  • Option A (Quadtree): Premier hierarchical raster data compression structure.
  • Option C (Run-length encoding): Linear row raster compression scheme.
  • Option D (Block encoding): 2D square raster compression scheme.
