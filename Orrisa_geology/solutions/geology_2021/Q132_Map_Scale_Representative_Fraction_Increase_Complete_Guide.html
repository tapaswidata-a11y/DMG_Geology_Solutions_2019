Question 132: As the scale of a map increases, e.g., 1 : 100000 to 1 : 50000, the relative size of the features will :

  • (A) Decrease
  • (B) Increase

2. Detailed Geological Masterclass: Map Scale and Feature Dimensions

Map scale is defined as the mathematical ratio between a distance measured on the map ($d_{\text{map}}$) and the corresponding distance measured on the ground ($D_{\text{ground}}$):

$$\text{Scale} = \frac{d_{\text{map}}}{D_{\text{ground}}} = \text{Representative Fraction (RF)}$$
  • Large Scale vs Small Scale:
    • $1 : 100,000 = \frac{1}{100,000} = 0.00001$
    • $1 : 50,000 = \frac{1}{50,000} = 0.00002$
    • Because $0.00002 > 0.00001$, moving from $1:100,000$ to $1:50,000$ represents an increase in map scale (it becomes a larger-scale map).
  • Relative Feature Size on the Map:
    • On a $1:100,000$ map, a $1\text{ km}$ ground feature is depicted as $1\text{ cm}$.
    • On a $1:50,000$ map, the same $1\text{ km}$ ground feature is depicted as $2\text{ cm}$.
    • The linear dimension doubles, and the surface area displayed on paper increases by fourfold ($2^2 = 4$).
  • Therefore, as the map scale increases, the relative size of geographic features on the map will Increase.

3. Critical Option Elimination & Exam Traps

  • Option B (Increase) is correct: Higher scale (larger fraction) renders ground features larger on paper/screen.
  • Option A (Decrease): Common confusion: candidates mistake the smaller denominator number ($50,000 < 100,000$) for a smaller scale. In fractions, $1/50,000$ is twice as large as $1/100,000$!
  • Option C & D: False; feature sizes directly scale with RF.
