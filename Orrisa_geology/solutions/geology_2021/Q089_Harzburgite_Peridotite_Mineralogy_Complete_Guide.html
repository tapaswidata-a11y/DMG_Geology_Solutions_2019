1. Question & Ultramafic Mineralogy

Question 89: Harzburgite is an ultramafic plutonic rock composed essentially of :

  • (A) Olivine + orthopyroxene
  • (B) Olivine + clinopyroxene
  • (C) Olivine + plagioclase
  • (D) Clinopyroxene + plagioclase

Correct Answer: (A) Olivine + orthopyroxene

2. Detailed Geological Masterclass: IUGS Peridotite Classification

Ultramafic rocks containing $>40\%$ olivine are called peridotites, and are categorized on the Olivine - Orthopyroxene - Clinopyroxene ternary diagram:

Rock Name Essential Minerals Mantle / Ophiolite Significance
Dunite $>90\%$ Olivine Extreme refractory mantle residue / cumulate
Harzburgite Olivine + Orthopyroxene (enstatite) ($<10\%$ Cpx) Depleted residual mantle peridotite (dominant in ophiolite mantle sections)
Wehrlite Olivine + Clinopyroxene (diopside) ($<10\%$ Opx) Cumulate peridotite / metasomatized mantle
Lherzolite Olivine + Orthopyroxene + Clinopyroxene Fertile, primitive upper mantle composition

Part III: Synthesis Reference Tables & High-Yield Practice

3. Critical Option Elimination & Exam Traps

  • Option A (Olivine + orthopyroxene) is correct: Harzburgite is strictly defined as an orthopyroxene-peridotite.
  • Option B (Olivine + clinopyroxene): Defines wehrlite.
  • Option C (Olivine + plagioclase): Defines troctolite (mafic gabbroic rock, not ultramafic peridotite).
  • Option D (Clinopyroxene + plagioclase): Defines standard gabbro.
