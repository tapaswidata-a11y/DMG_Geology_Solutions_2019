2. Detailed Geological Masterclass: Granulometric Analysis (Grain Size Analysis)

Granulometric analysis (or mechanical grain-size analysis) is the fundamental quantitative procedure used by sedimentologists to determine the grain size frequency distribution and the percentage of individual size classes in a clastic sediment sample:

  • Techniques Used:
    • Sieve Analysis: Using a nested stack of standard wire-mesh sieves (Wentworth / Udden phi scale intervals, $\phi = -\log_2 d$) for coarse sand and gravel fractions ($>0.0625 ext{ mm}$).
    • Pipette / Hydrometer Method: Based on Stokes' Law settling velocity for silt and clay mud fractions ($<0.0625 ext{ mm}$).
    • Laser Diffraction / Settling Tubes: Modern automated instrumentation.
  • Output & Statistical Parameters: Produces cumulative frequency curves and histograms, allowing calculation of graphic median ($Md$), mean ($M_z$), sorting (inclusive graphic standard deviation $\sigma_I$), skewness ($Sk_I$), and kurtosis ($K_G$).
  • Gravimetric Analysis: An analytical chemistry technique measuring mass or change in mass to quantify analyte concentration, not grain size distributions.
  • Sedimentation Analysis: While sedimentation settling is one method used to measure fine particles, the overarching scientific analysis to determine grain size distribution across all fractions is Granulometric analysis.

3. Critical Option Elimination & Exam Traps

  • Option A (Granulometric analysis) is correct: The universal sedimentological term for grain size distribution analysis.
  • Option B (Gravimetric analysis): Chemical analytical method measuring precipitation weight.
  • Option C (Sedimentation analysis): Only measures settling velocity for silt/clay; cannot be used for gravels and sands.
  • Option D: Gravimetric analysis is not grain size analysis.
